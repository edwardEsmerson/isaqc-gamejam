# Runtime assets

Put approved PNG sprite sheets, tilesets, audio, and atlas JSON here. Vite copies
these files into the build; load them with relative URLs such as
`assets/characters/player.png` so the game also works under a hosted subdirectory.

Use lowercase kebab-case filenames. Keep source artwork in `assets/source/` at
the repository root and record imported assets in `THIRD_PARTY.md`.

No PixelLab assets have been generated or imported yet.
