# Qubit FC demo pointers

- **Intro:** Six-a-side football; every completed teammate pass applies the receiver’s quantum gate.
- **Modes:** Local multiplayer, practice vs AI, gate drill, spectator.
- **HUD:** Bloch arrow = state; length = strength; gold marker = target; show odds and pass preview.
- **Gate drill:** H → Z → H: north → superposition → phase flip → south. Shoot.
- **Other gates:** X flips north/south; S and S† undo each other. Keeper RESET restores fresh north.
- **Football:** Move, sprint, aim passes, charge shots, switch defenders; control follows reception.
- **Keeper reading:** Switch Z ↔ X; changes scoring odds. Rotation freezes in the box.
- **Shots:** Beat keeper → measurement → goal or collapsed-state rebound. Goals reroll targets.
- **Defense:** Pressure weakens state toward 50% odds; outfield turnovers measure north/south.
- **Split:** One ball, two paths. Move support gates into lanes → change exit odds → interference selects outlet.
- **Path defense:** Touching a ghost measures the path: interception or surviving ordinary pass.
- **Finish:** Two halves, match stats; keyboard/gamepads, sound, fullscreen, pause, reduced motion, Expert hides phase.

**P1 controls:** WASD move · Shift sprint · F pass · hold/release G shoot · Q split · H switch/support · R own keeper reading · Esc pause.
